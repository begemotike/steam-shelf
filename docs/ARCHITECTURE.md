# Steam Shelf — Architecture

Read RESEARCH.md for the API facts this relies on, DESIGN.md for every visual value. This document is the contract for types, files and build configuration. Where a code snippet is given, treat its API calls as the verified shape to use; names of our own types must match exactly.

## 0. Ground rules

- **No third-party dependencies.** Frameworks used: SwiftUI, SwiftData, RealityKit, CoreGraphics, CoreText (via SwiftUI only), Security, AppKit (only `NSApp.currentEvent`, `NSCursor`, `NSWorkspace`), Foundation, XCTest.
- **Swift 6 language mode, strict concurrency complete.** Default actor isolation is **nonisolated** (do NOT set `SWIFT_DEFAULT_ACTOR_ISOLATION`). Mark every view model and SwiftUI-adjacent class `@MainActor` explicitly. All model structs are `Sendable`, `Codable`, `Equatable`.
- `CGImage` crosses actor boundaries only inside `struct SendableImage: @unchecked Sendable { let cgImage: CGImage }` (defined in `ArtGenerator.swift`). This avoids any SDK-version Sendable ambiguity.
- Deployment target **macOS 15.0**. Swift version setting `6.0` (built by Swift 6.4 toolchain).
- Bundle id `net.outofajam.SteamShelf`, product name `SteamShelf`, display name "Steam Shelf".

## 2. File responsibilities and key signatures

### App/SteamShelfApp.swift
```swift
@main struct SteamShelfApp: App {
    @State private var appModel: AppModel   // built in init()
    let container: ModelContainer            // SwiftData; in-memory when demo or under tests
    init()
    var body: some Scene {
        Window("Steam Shelf", id: "shelf") { ShelfView().environment(appModel) }
            .windowStyle(.hiddenTitleBar)
            .defaultSize(width: 1180, height: 960)
            .windowResizability(.contentMinSize)
            .commands { ShelfCommands(model: appModel) }
        Settings { SettingsView().environment(appModel) }
    }
}
struct ShelfCommands: Commands  // "Refresh Library ⌘R", "Export Shelf… ⇧⌘E", "Import Shelf… ⇧⌘I", "Next Page ⌘→", "Previous Page ⌘←"
```
- `init()` computes `LaunchMode`: `.tests` if `ProcessInfo.processInfo.environment["XCTestConfigurationFilePath"] != nil`, `.demo` if arguments contain `--demo`, else `.normal`.
- `ModelContainer(for: ShelfRecord.self, configurations: ModelConfiguration(isStoredInMemoryOnly: mode != .normal))`.
- Builds `AppModel(mode:container:)`. In `.tests` mode AppModel does nothing on launch (no network, no disk writes).
- Use `Window` (single window), not `WindowGroup`.

### App/AppModel.swift — the single source of UI state
```swift
enum LaunchMode: Sendable { case normal, demo, tests }

    // Entry edits (back-of-box panel)
    func update(_ appID: Int, _ mutate: (inout ShelfEntry) -> Void)   // mutates document, updatedAt = now, scheduleSave()
    // Paging
    func go(to page: Int)                   // clamps, sets slideDirection, withAnimation(Theme.Motion.pageSlide)
    func handleTapped(_ side: HandleSide)   // reads NSApp.currentEvent?.clickCount; uses Pagination.target
    // Open / close
    func open(_ appID: Int, from frame: CGRect)
    func close()
    // Demo
    func startDemo()                        // swaps source to DemoShelfSource, library to DemoData.library
    // Export / import
    func exportData() throws -> Data        // ShelfDocumentCodec.encode(document.forSharing())
    func importDocument(_ data: Data) throws // decode, replace document, save
    // Private
    private func scheduleSave()             // debounce 0.5 s via a stored Task; calls source.save(document)
    private func blurbIfNeeded(for appID: Int) async  // asks backOfBox provider when entry.blurb == nil or its inputs changed
}

enum SlideDirection: Sendable { case forward, backward }
```
Rules:
- `pageIndex` is re-clamped whenever the shelved count changes (`pagination.clamp(pageIndex)`).
- `document.shelvedEntries` is the ordered list rendered on the shelf.
- Errors from SteamClient are mapped to user strings via `SteamError.userMessage` and put into `libraryState = .failed(msg)`.
- In `.demo` mode every network method is a no-op; `hasAPIKey` is irrelevant.

### Model/ShelfDocument.swift — the canonical, shareable document
```swift
struct ShelfDocument: Codable, Sendable, Equatable {
    static let currentVersion = 1
    var version: Int = ShelfDocument.currentVersion
    var id: UUID
    var title: String                     // e.g. "Michael's Shelf"
    var owner: ShelfOwner
    var createdAt: Date
    var updatedAt: Date
    var entries: [ShelfEntry]             // ORDER IS CANONICAL (shelf order)

    var shelvedEntries: [ShelfEntry] { entries.filter(\.isShelved) }
    func forSharing() -> ShelfDocument    // copy with only shelved entries (future P2P payload)
    static func empty(owner: ShelfOwner) -> ShelfDocument
    mutating func insertSorted(_ entry: ShelfEntry)   // v1 ordering: case-insensitive title, localizedStandardCompare
}

struct ShelfOwner: Codable, Sendable, Equatable {
    var steamID64: String?
    var displayName: String               // persona name or "My Shelf"
    var avatarURL: String?
}

struct ShelfEntry: Codable, Sendable, Equatable, Identifiable {
    var id: Int { appID }
    var appID: Int
    var title: String
    var isShelved: Bool                   // unchecked games keep their notes/rating but leave the shelf
    var rating: Int?                      // 1...5, nil = unrated
    var note: String                      // "" default, max 600 chars enforced in UI
    var purchaseDate: Date?               // user-entered; Steam doesn't expose it
    var firstSeenAt: Date                 // first time this app saw the game in the library
    var stats: CachedSteamStats
    var art: ArtRefs
    var blurb: BackOfBoxContent?          // provider output, travels with the document
}

struct CachedSteamStats: Codable, Sendable, Equatable {
    var playtimeMinutes: Int
    var lastPlayed: Date?
    var hasCommunityStats: Bool
    var achievementsEarned: Int?
    var achievementsTotal: Int?
    var achievementsState: AchievementsState   // .unknown, .none, .privateProfile, .ok
    var fetchedAt: Date?
}
enum AchievementsState: String, Codable, Sendable { case unknown, none, privateProfile, ok }

struct ArtRefs: Codable, Sendable, Equatable {
    var portraitURLs: [String]            // ordered candidates, best first (from CoverURLs.portraitCandidates)
    var headerURL: String?
}

enum ShelfDocumentCodec {
    static func encode(_ doc: ShelfDocument) throws -> Data   // JSONEncoder: .iso8601, [.prettyPrinted, .sortedKeys]
    static func decode(_ data: Data) throws -> ShelfDocument  // .iso8601; throws DocumentError.unsupportedVersion(v) if v > currentVersion
}
enum DocumentError: Error, Equatable { case unsupportedVersion(Int) }
```
- JSON is the single serialized form (export file extension `.steamshelf`, UTType conforming to `public.json`; declare it in `Info.plist` as an **exported type** `net.outofajam.steamshelf`).
- Unknown JSON keys are ignored by `JSONDecoder` by default — this is the forward-compat story; new optional fields must be `Optional` or have custom `init(from:)` defaults.
- Cover art is stored as **URLs**, never image bytes, so a future peer can render the shelf keylessly from the public CDN.

### Model/Pagination.swift — pure, fully unit-tested
```swift

struct Pagination: Equatable, Sendable {
    static let columns = 4, rows = 4, perPage = 16
```

### Steam/SteamClient.swift
```swift
enum SteamError: Error, Equatable, Sendable {
    case missingKey, invalidKey, badSteamIDInput, vanityNotFound, profileNotFound
    case gameDetailsPrivate, privateProfile, noStats, rateLimited
    case http(Int), network(String), decoding(String), steam(String)
    var userMessage: String       // human text, see DESIGN.md §9 copy table
}

actor SteamClient {
    init(session: URLSession = .shared)
    static let apiBase = URL(string: "https://api.steampowered.com")!

    func resolveSteamID(_ input: SteamIDInput, key: String) async throws -> String
    func playerSummary(steamID: String, key: String) async throws -> PlayerSummary
    func ownedGames(steamID: String, key: String) async throws -> [OwnedGame]
    func achievements(appID: Int, steamID: String, key: String) async throws -> AchievementSummary
    func storeAssets(appIDs: [Int]) async throws -> [Int: StoreAssets]     // keyless GetItems, batches of 100, keyed by `id`, success == 1 only

    // Internal
    private func get(_ path: String, query: [URLQueryItem]) async throws -> (Data, HTTPURLResponse)
    // Pure static parsers — the unit tests call these directly with fixture Data:
    static func parseVanity(_ data: Data) throws -> String
    static func parseSummaries(_ data: Data) throws -> PlayerSummary
    static func parseOwnedGames(_ data: Data) throws -> [OwnedGame]      // games == nil && game_count == nil -> .gameDetailsPrivate ; game_count == 0 -> []
    static func parseAchievements(_ data: Data, status: Int) throws -> AchievementSummary
    static func parseStoreItems(_ data: Data) throws -> [Int: StoreAssets]
    static func checkStatus(_ status: Int) throws                          // 401/403 -> invalidKey, 429 -> rateLimited, other non-2xx -> http(n)
}
```
- `get` builds URLs with `URLComponents` (never string concatenation — it percent-encodes `input_json`). Timeout 20 s (`URLRequest.timeoutInterval`).
- For `achievements`, call `parseAchievements(data, status:)` **before** `checkStatus` (JSON error bodies on 400/403 — RESEARCH §1.4).
- The key is passed per call and never logged. Do not include the key in any error string.

### Persistence/ShelfStore.swift — SwiftData + ShelfSource
```swift
@Model final class ShelfRecord {
    @Attribute(.unique) var shelfID: UUID
    var kindRaw: String            // "local" in v1; "peer" reserved
    var updatedAt: Date
    var documentData: Data         // ShelfDocumentCodec JSON
    init(shelfID: UUID, kindRaw: String, updatedAt: Date, documentData: Data)
}

@MainActor protocol ShelfSource: AnyObject {
    var sourceID: String { get }          // "local", "demo", later "peer:<id>"
    var isEditable: Bool { get }
    func load() throws -> ShelfDocument?
    func save(_ document: ShelfDocument) throws
}

@MainActor final class LocalShelfSource: ShelfSource   // ModelContext(container) ; one ShelfRecord with kindRaw "local"
@MainActor final class DemoShelfSource: ShelfSource    // holds the doc in memory, isEditable = true, save() just stores
```
Why SwiftData stores one JSON blob per shelf (not per-entry models): the document is the canonical shape; per-entry `@Model` classes would duplicate the schema and need migration logic twice. The table still gives us a place to store additional shelves (peer shelves, later) by `kindRaw`. Pinned in OPEN_QUESTIONS Q4.

Future `PeerShelfSource` (not built): `isEditable = false`, `load()` returns the last received `ShelfDocument`; `save` throws. `AppModel` already reads `source.isEditable` to hide editing UI.

### Images/ImageCache.swift
```swift
actor ImageCache {
    init(fileManager: FileManager = .default, session: URLSession = .shared)
    func cover(for entry: CoverRequest) async -> CoverResult
    func clearMemory()
}
struct CoverRequest: Sendable, Hashable { let appID: Int; let title: String; let portraitURLs: [String]; let headerURL: String? }
enum CoverResult: Sendable {
    case portrait(SendableImage)                  // real 2:3 art
    case header(SendableImage)                    // landscape art — caller composites via ArtGenerator.headerCover
    case none                                     // caller generates placeholder
}
```
Algorithm for `cover(for:)`:
1. Memory dict `[Int: CoverResult]` hit → return.
2. Disk `Caches/SteamShelf/covers/{appID}.jpg` exists → decode (`CGImageSourceCreateWithURL` → `CGImageSourceCreateImageAtIndex`) → `.portrait`. `{appID}-header.jpg` → `.header`.
3. If `misses[appID]` younger than 7 days → `.none`.
4. Try each `portraitURLs` in order: `session.data(from:)`; accept only status 200 and MIME `image/*`; write bytes to disk; return `.portrait`.
5. Try `headerURL` the same way (save as `{appID}-header.jpg`) → `.header`.
6. Record miss, persist `misses.json`, return `.none`.
Coalesce concurrent requests for the same appID with `[Int: Task<CoverResult, Never>]` in-flight map. Memory map is capped at 200 entries (drop arbitrary when full). Downsample images larger than 1200 px tall using `kCGImageSourceThumbnailMaxPixelSize: 1200` + `kCGImageSourceCreateThumbnailFromImageAlways`.

### BackOfBox/BackOfBoxProvider.swift — the AI seam
```swift
struct BackOfBoxContext: Codable, Sendable, Equatable {
    let appID: Int
    let title: String
    let playtimeMinutes: Int
    let lastPlayed: Date?
    let firstSeenAt: Date
    let purchaseDate: Date?
    let achievementsEarned: Int?
    let achievementsTotal: Int?
    let rating: Int?
    let note: String
    let storeDetails: StoreDetailsLite?          // nil in v1 (appdetails not fetched)
    init(entry: ShelfEntry)
    var fingerprint: String                      // stable hash of inputs; provider output is reused while unchanged
}
struct StoreDetailsLite: Codable, Sendable, Equatable { let genres: [String]; let developer: String?; let releaseDate: String? }

struct BackOfBoxContent: Codable, Sendable, Equatable {
    var blurb: String                // 1–3 sentences, ≤ 280 chars
    var tagline: String?             // ≤ 40 chars, shown under the title
    var providerID: String           // "local.v1", later "ai.claude"
    var inputFingerprint: String
    var generatedAt: Date
}

protocol BackOfBoxProvider: Sendable {
    var providerID: String { get }
    func content(for context: BackOfBoxContext) async throws -> BackOfBoxContent
}

struct LocalBackOfBoxProvider: BackOfBoxProvider   // deterministic template quips — DESIGN.md §7.3 table
```
Future `AIBackOfBoxProvider` (NOT built): a `struct` holding an API-key accessor (Keychain account `ai-api-key`) and model id; `content(for:)` encodes `BackOfBoxContext` as JSON into a prompt, calls the provider over `URLSession`, returns `BackOfBoxContent` with `providerID = "ai.<vendor>"`. `AppModel.backOfBox` is the only switch point. Because `blurb` is stored in `ShelfEntry`, AI text generated by the owner ships to peers without them needing a key.

Regeneration rule (in `AppModel.blurbIfNeeded`): call the provider when `entry.blurb == nil` or `entry.blurb.inputFingerprint != context.fingerprint`. For the local provider the fingerprint covers `playtime bucket, achievements, rating` only (so typing a note doesn't reshuffle the joke).

Face construction (`MeshResource.generatePlane(width:height:)` = XY plane facing +Z):
| Face | Plane (w × h) | Position | Rotation | Material |
|---|---|---|---|---|
| front | W × H | (0, 0, +D/2) | none | cover |
| back | W × H | (0, 0, −D/2) | π about Y | back label |
| right | D × H | (+W/2, 0, 0) | +π/2 about Y | spine |
| left | D × H | (−W/2, 0, 0) | −π/2 about Y | spine |
| top | W × D | (0, +H/2, 0) | −π/2 about X | edge (spine color, roughness 0.7) |
| bottom | W × D | (0, −H/2, 0) | +π/2 about X | edge |
Rotations via `simd_quatf(angle:axis:)`, e.g. `simd_quatf(angle: .pi, axis: [0, 1, 0])`.

Back texture updates: `BoxStageView` keeps a reference to the back `ModelEntity`; when the entry changes (debounced 150 ms), re-render `BackOfBoxView` with `ArtGenerator.render`, create a new `TextureResource`, and assign `backEntity.model?.materials = [BoxBuilder.material(newTex, roughness: 0.6)]`.
